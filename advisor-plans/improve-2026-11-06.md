### 1. Prevent the hammock calculator from hanging on accepted input

**Problem:** A zero or negative minimum fold length can keep the calculation running indefinitely. The number input accepts these values. The page can consume CPU/memory instead of returning an error.

**Evidence:** `content/posts/hammock-suspension.md:60` has `required` but no positive `min`. `static/js/hammock-suspension.js:27` parses the value without validation; the loop at line 71 continues while `currentLength >= minFoldLength * 2`. At zero, repeated halving eventually reaches zero and still satisfies the condition. Running the actual submit handler in an isolated Node VM with a 150 ms timeout produced:

```text
HAMMOCK minimum=0  Script execution timed out after 150ms
HAMMOCK minimum=-1 Script execution timed out after 150ms
HAMMOCK minimum=20 Summary … Number of possible lengths: 47 … Range: 6.0 to 168.0 inches
```

The ordinary preset also completed in the live browser. Zero/negative cases were deliberately confined to the bounded VM. Filtering out nonpositive suspension lengths at JS line 33 also loses correspondence with the separately sliced type array at line 40.

**Proposed change:** Validate finite, positive lengths and fold minimums before generating combinations. Add native constraints and an accessible error. Preserve each input's length, type, and original index together. Update the Org authoring source as well as exported Markdown.

**Done state:** Invalid values return a clear error promptly; no input can cause an unbounded folding loop. A missing/interior invalid length cannot silently acquire another row's type. The existing preset still returns 47 lengths spanning 6–168 inches.

**Verification command:** Run Appendix A from this checkout. Zero and negative cases must return validation errors without timing out; retain the preset result. Then submit the preset through the real form and check errors with keyboard navigation. Do not exercise the known infinite loop in the shared browser before fixing it.

const vm = require('node:vm');
function probe(script, values, date) {
	const handlers = {}, elements = {};
	for (const [key, value] of Object.entries(values)) elements[key] = {value, innerHTML: ''};
